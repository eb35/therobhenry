<p>Yeah, that’s right! I’m keeping the original post. Not only do I need the content, especially that juicy test comment, but as a web developer, “Hello World” is step <em>numero uno</em> in learning any new technology.</p>

<p>And that is what I am doing here… Learning. As mentioned in my <a href="https://wordpress.therobhenry.com/about/">About</a> page, this site is a playground where I will be eventually breaking everything down, so that I can build it back up.</p>

<p>My plan is to start by using the lovely “Twenty twenty” theme. I used the Customizer to change the colors to this (IMO) sweet-looking dark mode. But eventually I will create my own theme, so that I can get my hands dirty and work directly with the inner workings of WordPress.</p>

<p>Then I will evaluate what modifications I made in the theme that should be plugins, so that they can be used in whatever other theme that I want to create or just grab the ginormous library of well-established and beautiful themes at my disposal.</p>

<p>I’m looking forward to working with the PHP code and utilitizing custom post types, but my true loves of web development are JavaScript and CSS. I can’t wait to make my site more interactive and beautiful.</p>

<p>But before I start my grand plans, I want to have content to work with. It’s no fun editing the “loop” when all my posts are just a title and one sentence or (God-forbid) just some Lorem Ipsum text. It’ll be fun paging through articles that I wrote myself.</p>

<p>So all that to say, my first posts will be all about my setup process and the initial steps that I have taken. Stay tuned!</p>
